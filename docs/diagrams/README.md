# 🗺️ Architecture and Workflow Diagrams

The diagrams in this directory describe current application behavior or explicitly label future architecture. They use Mermaid source so changes can be reviewed in Git.

| Diagram | Scope |
|---|---|
| [system-architecture.mmd](system-architecture.mmd) | Current browser-only runtime |
| [food-sharing-flow.mmd](food-sharing-flow.mmd) | Existing browse/post/claim UI journeys and simulation boundaries |
| [auth-flow.mmd](auth-flow.mmd) | Current mock authentication and localStorage |
| [future-trust-boundaries.mmd](future-trust-boundaries.mmd) | Conceptual controls needed before real exchanges |

Do not interpret a future-state diagram as an implemented system. Update diagrams when the route table, data flow, trust boundary, or service architecture changes.
