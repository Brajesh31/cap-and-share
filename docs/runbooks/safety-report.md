# 🥗 Runbook: Food-Safety or Listing Report

## Current availability

The prototype does not have a real listing database, report queue, moderator dashboard, or pickup workflow. This document is a proposed operating procedure for a future supervised service, not an existing capability.

## Proposed handling

1. Acknowledge the report without promising an outcome.
2. If a real exchange is imminent and safety is uncertain, advise the parties not to proceed until the concern is resolved.
3. Hide or pause the disputed listing if the service has a reliable moderation control.
4. Record only information necessary to assess the report.
5. Escalate suspected contamination, illness, allergen exposure, or other urgent harm to appropriate local authorities or institutional staff.
6. Review the listing details and donor response with an accountable moderator.
7. Record the decision, rationale, and any follow-up action.
8. Close the report only after the reporter has received an appropriate response.

## Principles

- Never label food safe based only on a photo or user assertion.
- Do not publish private contact details or medical information.
- Do not pressure anyone to consume food.
- Preserve an appeal/correction path for disputed reports.
- Obtain qualified local food-safety guidance before launching.
