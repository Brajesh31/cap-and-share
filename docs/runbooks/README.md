# 🧭 Operations Runbooks

These runbooks are reference procedures for maintainers. The current project is a static frontend prototype, so backend, account, moderation, and food-exchange operations described as future procedures are not currently available.

| Runbook | Purpose |
|---|---|
| [Local development](local-development.md) | Start and diagnose the Vite app |
| [Static deployment](static-deployment.md) | Publish and verify the built site |
| [Incident response](incident-response.md) | Triage a security, privacy, or service issue |
| [Content and safety report](safety-report.md) | Proposed workflow for a future real exchange |

Before using a procedure, confirm that its prerequisites and owners exist. Never claim an operational control is active merely because a runbook describes it.
