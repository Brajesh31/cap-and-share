# 📖 Glossary

| Term | Meaning in this repository |
|---|---|
| Cap'nShare | The campus surplus-food sharing interface concept |
| Food post | A sample `FoodPost` record displayed in the UI |
| Donor | A person or organization offering surplus food, as a product concept |
| Recipient | A person interested in a listed portion, as a product concept |
| Claim | The intended request to collect a listed item; currently simulated |
| Listing | A food post shown on the food browsing screen |
| Mock data | Fixed sample records imported from `src/data/mockData.ts` |
| Mock authentication | Client-side login/signup simulation without identity verification |
| BrowserRouter | React Router history-based routing used by the app |
| Static build | The generated files in Vite's `dist/` directory |
| Moderation | A future process for reviewing reports and problematic listings |
| Allergen disclosure | Information about known ingredients/allergens, which must not be treated as guaranteed complete |
| Prototype | A demonstration interface that is not suitable for actual food exchanges |

Use these terms consistently in issues, pull requests, and documentation.
