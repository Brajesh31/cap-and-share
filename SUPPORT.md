# Support

## Project questions and defects

Open an issue in the repository:

https://github.com/Brajesh31/cap-and-share/issues

Include the affected route, steps to reproduce, expected and observed behavior, browser and operating system, and relevant console or network output. Remove passwords, phone numbers, addresses, and other private details before posting.

Use the private reporting steps in SECURITY.md for vulnerabilities. Do not publish exploit details in an issue.

## Project scope

Cap'nShare is a client-side interface prototype with fixed sample listings and mock account flows. Support can address the source, local setup, and documented behavior. The repository does not operate a live campus exchange, verify users, coordinate real food pickup, or provide food-safety oversight.

The app relies on external image and font providers. Their availability and usage terms are outside this repository.

## Response expectations

The project is maintained by Brajesh Kumar (@brajesh31). There is no paid support plan or guaranteed response time. Please follow CODE_OF_CONDUCT.md when participating.
